# Image Prompts — dreamy direction

Works in Flow's image mode, Imagen, Midjourney, or Ideogram. One prompt per asset.
Set the aspect ratio in the tool before generating. Export the largest size offered, PNG.

Files to produce:

| File | Aspect | Used for |
|---|---|---|
| `hero-16x9.png` | 16:9 | Hero poster frame, and start+end frame for the desktop loop in Flow |
| `hero-9x16.png` | 9:16 | Hero poster frame, and start+end frame for the mobile loop in Flow |
| `track-1-hardware.png` | 3:4 | Themes gallery, Track 1 |
| `track-2-health.png` | 3:4 | Themes gallery, Track 2 |
| `track-3-fintech.png` | 3:4 | Themes gallery, Track 3 |
| `track-4-environment.png` | 3:4 | Themes gallery, Track 4 |
| `og-share.png` | 16:9 | Background of the link-preview card (text is added in code) |
| `not-found.png` | 16:9 | 404 page |

## Track images

All four share the world: dark meadow at night, painterly, off-white and champagne-gold light, near-black sky. No people in any of them. Each track is a single object standing in the grass, so the four panels read as four different things at a glance. Portrait 3:4, object centered, bottom fifth kept dark because the track label sits there.

## track-1-hardware.png (movie reference, vector illustration)

Aspect: 3:4

```
Flat vector illustration with smooth gradients, dreamy and painterly, no outlines. A dark meadow at night, tall grass and small white wildflowers filling the bottom third of the frame, near-black sky fading to deep charcoal at the horizon. In the center, a tall rectangular monolith robot stands in the grass: a slab of brushed dark metal about twice human height, split vertically into four articulated hinged segments, one outer segment swung out at an angle like an arm, a single narrow horizontal screen strip glowing near the top. Fine seams between the segments glow with soft champagne-gold light, and the screen strip glows off-white, the only light in the scene, catching the grass tips and wildflowers around its base. A small drone the size of a moth hovers beside the extended segment, its body glowing with the same gold light. A warm halo of the same light glows behind the robot. Tiny gold motes drift upward. Palette limited to near black, deep charcoal, off-white, champagne gold, and gunmetal grey for the robot body. Bottom fifth of the frame dark grass. No text, no logos, no readable labels on the screen.
```
